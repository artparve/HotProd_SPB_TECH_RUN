# Предварительная смета выбранных товаров

Проверено 2026-11-07. Java API и MongoDB запущены в отдельных временных контейнерах с учебным каталогом `synthetic-catalog-v2` и правилами `synthetic-rules-v2`. Рабочая база сервера не использовалась. Реальный Ollama `gemma4:12b` вызван через временный SSH-туннель к серверу; шлюз настроен на контекст 16384.

## Сквозной сценарий

В браузере `http://127.0.0.1:5176/`: комната 5×4 м, напольное покрытие, запас 10%; «Найти товары», выбор кварцвинила «Дуб песочный», явное подтверждение предварительного расчёта, «Рассчитать предварительную смету».

Java вернула 10 упаковок, материалы 36 900 ₽, работы 13 000 ₽, всего 49 900 ₽. Стоимость отобразилась до ответа модели. Ollama вернула отдельное пояснение, отображённое через безопасный Markdown-компонент. Текст модели не меняет смету.

- `estimate-ollama.jpg` — реальный интерфейс со стоимостью и ответом модели.
- `api-result.json` — отдельная проверка HTTP API с реальным инференсом (9,02 с), сравнением с обычным Java `/estimate` и отрицательными сценариями: без подтверждения 422, изменённая комната 409.

## Проверки

В Docker прошли TypeScript, 142 теста frontend и production build, 12 тестов LLM gateway. Maven verify: 101 модульный и 24 интеграционных теста на исходниках этой поставки, без параллельных изменений администрирования. Также прошли 27 интеграционных тестов совместного рабочего дерева.

Дополнительно проверяются отказ при чужом товаре, неполном выборе и истёкшем подборе; прежний строгий маршрут с проверенной базой знаний остаётся отдельным. Сбой модели сохраняет Java-смету в интерфейсе. Изменение комнаты сбрасывает результат и пояснение.

Это предварительный учебный расчёт. Совместимость товаров по PDF не подтверждается автоматически. Для рабочего сайта требуется выпуск через CI/CD.
