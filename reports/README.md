# Исторические отчёты

Здесь сохранены аудиты исходных данных, результаты ручных проверок, скриншоты и ограниченные отчёты предыдущих запусков. Они помогают разбирать регрессии и происхождение решений, но не нужны для сборки или запуска приложения.

Каталог исключён из общего поиска через `.ignore` и из Docker build context. Датированный отчёт описывает тот запуск, а не текущее состояние сервера. Скрипты внутри отчётов — исторические свидетельства, а не поддерживаемые команды эксплуатации.

Существующие отчёты сохранены. Новые проверки сохраняйте вне Git (например, в согласованной временной папке); перед публикацией любых логов проверяйте их на секреты. Удаление архива и переписывание истории Git — отдельная операция.
