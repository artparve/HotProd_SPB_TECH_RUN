## Связь каталогов

Точное совпадение найдено у 56 207 уникальных кодов: `JSON cod_good` соответствует числовому хвосту XML URL. Только XML — 5 199 кодов, только JSON — 32 539. У 36 общих кодов есть дубли JSON, поэтому прямое соединение без их разрешения размножает записи.

XML `offer/@id` и JSON `id` не совпадают. Артикул внутри XML param также не является уникальным ключом. Совпадение товарного кода не доказывает одинаковую свежесть цены или согласованность характеристик.

## Что уже есть и чего недостаёт

Материалов достаточно, чтобы начать прототип без нового массового парсинга сайта. Основные задачи подготовки: объединение источников, проверка фасовки/единиц/расхода и ограничение каталога ремонтными вертикалями.

Нужно создать эталон многометочной классификации, правила совместимости, справочник подтверждённых норм и коэффициентов, эталонные сметы и отдельный источник тарифов работ. Сведения о наличии, региональных ценах и API стенда требуют подтверждения. Нельзя считать товарные категории готовыми метками видов работ или превращать неявную норму расхода в достоверное число.
