# Подготовленная подборка интерьеров

Production `manifest.json` содержит четыре реальные фотографии Pexels: гостиную, спальню, кухню и ванную. JPEG шириной 1440 px занимают суммарно 641 626 байт. Авторы, исходные страницы, лицензия и контрольные суммы перечислены в [CREDITS.md](CREDITS.md). Фотографии включены в backend Docker image и автоматически импортируются командой init-data; ключи и сеть для показа подборки не нужны.

На 31.10.2026 [официальный API Pinterest](https://developers.pinterest.com/docs/getting-started/connect-app/) требует business account, регистрацию и одобрение приложения, а затем токен. [Общий поиск чужих пинов](https://github.com/pinterest/pinterest-python-generated-api-client/blob/main/docs/SearchApi.md) доступен только части приложений в beta. Это не общедоступный источник изображений без регистрации. По запросу пользователя вместо него подключена локальная подборка по [Pexels License](https://www.pexels.com/license/), разрешающей использование фотографий в приложениях.

Чтобы расширить или заменить подборку, поместите сюда PNG/JPEG с разрешением на использование и внесите записи:

```json
[
  {
    "id": "living-01",
    "title": "Гостиная",
    "description": "Описание интерьера",
    "alt": "Доступное описание изображения",
    "file": "living-01.jpg",
    "sourceUrl": "https://www.pexels.com/photo/<photo-slug-and-id>/"
  }
]
```

Нужны сам локальный файл и HTTPS-ссылка на исходную страницу Pexels либо Pinterest (`pexels.com`, `www.pexels.com`, `pinterest.com`, `www.pinterest.com`, `pin.it`). URL с credentials, нестандартным портом или похожим чужим доменом отклоняется. Загрузчик ничего не скачивает. Добавьте автора в описание и обновите CREDITS.md; Pinterest-ссылка сама по себе не даёт прав на изображение. `id` стабилен, состоит из латинских букв, цифр, `_` и `-`, до 128 символов. Пустой `[]` остаётся допустимым для собственной установки.

До импорта проверяются дубли, путь (включая symlinks), формат, размер файла, pixel limit и метаданные. Затем весь набор метаданных заменяется одной транзакцией. Превью генерируется из локального оригинала. Изменение файла после импорта обнаруживается по SHA-256.

Для локального backend: `make backend-import-inspirations`. Для Docker добавьте файлы до сборки образа и повторите bootstrap, либо смонтируйте каталог read-only одновременно в backend и init-data и задайте INSPIRATIONS_DIR/INSPIRATIONS_MANIFEST. При смене образа перезапустите backend после импорта.

Модель предлагает тип покрытия и отделку стен. Java подбирает совместимые товары и проверяет полный комплект; цвет, фактура и точный товар по фото не подтверждаются. Размеры всегда берутся из формы. При отсутствии подходящего материала/сервиса исходный проект сохраняется.

Базовый Docker smoke проверяет именно production-фотографии, их байты и превью, а также `unavailable` анализа без Python/Ollama. Проверка с модельным транспортом копирует настоящую фотографию из подборки во временный каталог с отдельным тестовым ID; JPEG проходит Java → Python → модельный транспорт. Тестовая запись в production manifest не добавляется. Качество распознавания фотографий настоящей моделью требует отдельного LLM smoke.
