# Подготовленная подборка Pinterest

Production `manifest.json` изначально содержит `[]`. Поместите сюда подготовленные PNG/JPEG и внесите записи:

```json
[
  {
    "id": "living-01",
    "title": "Гостиная",
    "description": "Описание интерьера",
    "alt": "Доступное описание изображения",
    "file": "living-01.jpg",
    "sourceUrl": "https://www.pinterest.com/pin/<pin-id>/"
  }
]
```

Нужны сам локальный файл и ссылка на исходный pin; одной Pinterest-ссылки недостаточно для импорта. Загрузчик ничего не скачивает и не использует scraping/API Pinterest. `id` стабилен, состоит из латинских букв, цифр, `_` и `-`, до 128 символов.

До импорта проверяются дубли, путь (включая symlinks), формат, размер файла, pixel limit и метаданные. Затем весь набор метаданных заменяется одной транзакцией. Превью генерируется из локального оригинала. Изменение файла после импорта обнаруживается по SHA-256.

Для локального backend: `make backend-import-inspirations`. Для Docker добавьте файлы до сборки образа и повторите bootstrap, либо смонтируйте каталог read-only одновременно в backend и init-data и задайте INSPIRATIONS_DIR/INSPIRATIONS_MANIFEST. При смене образа перезапустите backend после импорта.

Модель предлагает тип покрытия и отделку стен. Java подбирает совместимые товары и проверяет полный комплект; цвет, фактура и точный товар по фото не подтверждаются. Размеры всегда берутся из формы. При отсутствии подходящего материала/сервиса исходный проект сохраняется.

Тестовая картинка `scripts/verify-stack.py` существует только во временном каталоге отдельного тестового проекта и в production manifest не добавляется.
