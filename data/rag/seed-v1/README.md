# Начальная коллекция RAG: черновик

Дата сбора: 07.11.2026. В `chunks.jsonl` — 13 коротких самостоятельных пересказов по шести продуктам, в `sources.json` — шесть ссылок на первичные источники производителя. `evaluation.jsonl` содержит небольшие диагностические запросы; это не независимая приёмочная выборка. Продукты включают пять позиций из пользовательского demo и дополнительную грунтовку для поиска по работам с краской и обоями.

Каждая строка фрагмента содержит стабильный ID, черновой `product_ref`, категорию, тип факта, текст, источник и раздел. Значения `review_status=draft` и `usable_for_decisions=false` обязательны: исследовательская коллекция не опубликована, не является каталогом SKU и не предназначена для автоматического подбора, расчёта или обучения правил. `product_ref` не сопоставлен с внутренним ID RepairCalc. Отсутствие свойства означает «неизвестно», а не отрицание. Данные по дизайну, ценам, наличию, упаковкам и расходу здесь не установлены; генерация не должна их придумывать.

Источники просмотрены через поисковый индекс и текстовое представление страниц; полная экспертная сверка технических листов, актуальности, прав использования и точного соответствия карточек ещё не выполнена. В корпусе нет копий документов. Веб-страницы могут измениться, а приведённые URL сами по себе не подтверждают права на повторное распространение или индексирование. До продуктивного использования согласовать права, сохранить допустимые версии документов и хеши, проверить контекст каждого фрагмента и утвердить карточки и правила через администрирование. Цитирование производителя не заменяет техническую проверку.

Файл demo не импортирован целиком: его числовые нормы, цены, размеры упаковок и некоторые ссылки не проверены для этой коллекции. Например, диапазон расхода Флэхендихта в demo не отражает различий поверхности; подробные условия приведены в документе производителя. Не переносить эти значения в расчёт без отдельной проверки. Флизен и Флизен Плюс — разные товары; применимость одного не распространяется на другой. Ротбанд в ванной требует защиты от увлажнения. Источник Флэхендихта описывает ограничения по типу клея; не следует автоматически делать вывод о совместимости конкретной пары.

## Проверка и использование для эксперимента

Для офлайн-проверки формата: `python3 -m json.tool data/rag/seed-v1/sources.json >/dev/null` и разбор каждой строки JSONL. При экспериментальном индексировании использовать `id` как ID фрагмента и сохранять `source_id`, `source_section`, `product_ref`, `kind` и статус. Положительные и отрицательные фрагменты одного товара извлекать вместе; фильтрация и решение о совместимости всегда выполняются отдельно от RAG. Набор намеренно мал и сосредоточен на одной марке и черновых работах в санузле; он не покрывает весь каталог, типы ремонта и дизайн. Для релиза нужны более широкий лицензированный корпус и независимая экспертная разметка по спецификации.
