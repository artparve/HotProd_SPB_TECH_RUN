# Организация репозитория

- Корень: README, Makefile, AGENTS и служебные Git/Docker/search-настройки.
- `docs/reference/`: постановка задачи и исторический план; `assets/` — исходные картинки и DOCX, не runtime-ресурсы.
- `data/`: версионированные учебные каталог/правила и фотографии, которые действительно входят в приложение. Загрузка Mongo описана в [data/README.md](../data/README.md).
- `scripts/release.py`: единственная реализация релизного CLI. Корневая обёртка `release.py` удалена; используйте `python -m scripts.release` или `python scripts/release.py`. CD уже вызывал модуль из `scripts/`.
- `reports/`: исторические аудиты, логи проверок и скриншоты. Для запуска не нужны; сохранены как свидетельства. Подробнее — [reports/README.md](../reports/README.md).
- `.ignore`: правила **поиска ripgrep**, чтобы зависимости, сборки и отчёты не засоряли результаты. Это не `.gitignore`: файл не управляет Git и не защищает секреты. Для точечного доступа к отчётам используйте `rg --no-ignore ... reports/<каталог>`.
- `.idea/`: локальные настройки IntelliJ IDEA, больше не отслеживаются Git.
- `.run/`: IDE-конфигурации запуска Java/Maven. Они не нужны Make, CI или Docker; больше не отслеживаются Git, локальные копии сохранены. Поддерживаемый локальный запуск — `make backend` с общим загрузчиком конфигурации.
- `__pycache__/` и `*.pyc`: автоматически создаваемый байткод Python для ускорения импорта. Можно удалить без потери исходников; при обычном запуске появится снова. Исключены из Git, общего поиска и Docker. Для запуска без создания кеша используйте `python -B ...`.
- `env/.env`: общий **несекретный** конфиг в Git, без отдельного `.env.example`; `env/.env.local` — необязательные приватные машинные overrides. Прежний локальный `.env` сохранён там при переходе.
- `env/secret.env`: реальные секреты, никогда не отслеживаются Git. `env/secret.env.example` содержит те же имена, но пустые значения. Синхронизация — `make init-config`; существующие значения не перезаписываются, старые ключи сначала архивируются в игнорируемый `secret.env.legacy`. Пустые Mongo/LLM-ключи необходимо заполнить самостоятельно.

Ранее закоммиченные `.idea` и `.run` остаются в старой истории Git; очистка истории этой задачей не выполняется.
