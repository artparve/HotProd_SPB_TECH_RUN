# Административный процесс

Java хранит карточки, immutable versions, задания, человеческие решения, публикации и аудит в MongoDB. Python получает только входные данные классификации по защищённому внутреннему HTTP; DB-реквизиты ему не передаются.

1. Открыть /api/v1/admin/session, войти с CSRF-токеном. Настроенные credentials включают admin; для локального HTTP cookie secure отключается явно.
2. Создать черновик с внешней идентичностью. Неизвестные значения отмечаются unknown/unset, подтверждённые содержат источник и автора из сессии.
3. Изменять карточку с If-Match. Новая версия отменяет применимость старой классификации/review. Устаревшее изменение — 412; отсутствующий If-Match — 428.
4. Поставить текущую версию в очередь. Java получает задание атомарно, обновляет lease и принимает завершение только с действующим токеном. Повтор запроса не создаёт дубль; failed можно явно перезапустить. Busy не расходует попытку. Результат старой версии не публикуется.
5. Успешная классификация текущей версии автоматически сопоставляется с Java-работами, без ручных решений по каждой метке. Для грунта нужны priming + wall, для плиточного клея tile + floor. Если поверхность не определена, укажите её в описании при наличии источника, сохраните новую версию и снова запустите классификацию. Модельные метки и цитаты остаются доступны в ответе задания; применение не означает человеческую проверку или подтверждение фактической точности.
6. Readiness автоматически выбирает совместимый профиль по виду, единице и подтверждённому значению расхода; если подходящего или однозначного профиля нет, публикация блокируется. Проверяются необходимые факты, норма с единицей, упаковка/рулон и источники. При публикации сохраняется отдельная запись автоматического сопоставления с идентификатором задания, каталог копируется с заменой одной ревизии, правила обновляются, указатель пары, статус и аудит переключаются одной транзакцией. Повтор publish идемпотентен. Существующий API ручной проверки сохраняется для совместимости, но не обязателен для публикации.

Дата в Mongo хранится BSON Date; наружу отдаётся ISO UTC. UUID, ETag, состояния и snake_case полей review/publication сохранены в публичном контракте. Денежные значения — Decimal128/BigDecimal и decimal-строки RUB.

Цены и нормы MVP учебные. Неизвестная необходимая пригодность исключает товар из комнатного подбора. Отсутствие обязательных данных блокирует смету/публикацию; недоступность хранилища возвращает 503 с безопасной ошибкой. Session storage пока in-memory: после рестарта Java вход выполняется заново.

Контракты: docs/admin-catalog-api.json и docs/openapi.yaml. Транзакции/конкуренция/lease проверяются MongoWorkflowIT, полный путь HTTP — scripts/verify-stack.py.
