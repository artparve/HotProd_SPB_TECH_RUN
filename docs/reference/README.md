# Исходные материалы и исторические планы

Сюда перенесены из корня постановка задачи, ответы организаторов, инвентаризация и ранний план. В `assets/` — исходный DOCX, архитектурный эскиз, примеры планов комнат и иллюстрации. Они не участвуют в сборке приложения и исключены из Docker build context.

Исторические документы могут упоминать прежние корневые имена и старый стек. Текущая архитектура — в `../AI_CONTEXT.md`, инструкции запуска — в `../../README.md`.

`assets/feature*.jpg` и другие исходные изображения не добавлены в публичную галерею: права на их повторное использование не установлены. Галерея использует лицензированные фотографии из `../../data/inspirations/`.
