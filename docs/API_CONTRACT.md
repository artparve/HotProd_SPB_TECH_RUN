# Контракт frontend ↔ RepairCalc

Основной контракт теперь описан в **[openapi.yaml](openapi.yaml)** (OpenAPI 3.0.3). Файл можно открыть в Swagger Editor, подключить к Swagger UI или использовать для генерации клиента. Структура и ссылки проверяются автоматически вместе с frontend-тестами.

Java 21 backend (BE-02–14) реализует витрину и калькулятор одного товара по этому контракту. Подготовлены 12 учебных карточек: 11 рассчитываются, одна явно заблокирована из-за неполных данных. Отдельный [Python estimation-сервис](../backend/estimation/README.md) реализует вызов Ollama с расчётным tool и пояснением; арифметика остаётся в Java. Общая смета, рекомендации, полный потоковый импорт JSON/XML и admin API ещё не реализованы. Внешний Bagisto API из DOCX требует отдельной нормализации.

Запуск для команды: [Windows, Linux и macOS](../backend/docs/TEAM_SETUP.md); детали и проверки: [backend/README.md](../backend/README.md).

## Маршруты

Базовый URL: `/api/v1`.

| Метод | Путь | Назначение | Состояние |
| --- | --- | --- | --- |
| GET | `/products` | Ограниченная нормализованная витрина товаров для виджета | Реализовано |
| POST | `/estimate` | Материалы и отдельно ориентировочные работы | Запланировано |
| POST | `/recommendations` | Товары под условия комнаты с объяснением | Запланировано |
| POST | `/product/{id}/calc` | Расчёт одного товара без стоимости работ | Реализовано |
| POST | `/materials/estimate` | Ollama → расчётный tool → Java → пояснение | Реализовано отдельным Python-сервисом, подключено к карточке товара |
| POST | `/materials/calculate` | Baseline и необязательная поправка без Ollama | Реализовано отдельным Python-сервисом |

Точные поля, обязательность, ограничения, nullable-значения, ответы и ошибки находятся в OpenAPI, а не дублируются в этом файле. `frontend/src/domain/types.ts` и `frontend/src/domain/materials.ts` содержат соответствующие Zod-схемы runtime-проверки. Клиент пока написан вручную; генерация из OpenAPI не подключена.

В `MaterialEstimate` суммы берутся только из `estimate`; `explanation` — непроверенный текст модели. `estimate.versions.model=not-used` относится к арифметике Java, верхний `model` указывает помощника. Для `/materials/estimate` обязательный tool call проверяется сервисом, отсутствие вызова даёт 502, без скрытого fallback. Сбой только последнего пояснения сохраняет смету и даёт `explanationStatus=unavailable`.

## Важные договорённости

- Денежные суммы — десятичные строки в RUB. Цена относится к **единице продажи**, не к произвольной площади или массе.
- `quantity` в строке сметы — целое число единиц продажи. `need`, `purchased` и `remainder` выражены в `product.unit`.
- Для обоев `unit` — полотна, а единица продажи — рулон. Backend учитывает длину полотна, раппорт и подрезку.
- Для будущего подбора условия влажности, нагрузки и отопления передаются явно. Неизвестная совместимость не означает разрешённую.
- Для будущей общей сметы `selections` связывает ключ `roomId:productKind` с `productId`; backend должен повторно проверять выбор, цену и доступность.
- Общая смета потребует серверной проверки геометрии: проёмы меньше площади стен; обои и краска не отделывают одновременно всю одну поверхность.
- Нельзя выдумывать расход или брать среднее диапазона без условий. Недостаток данных — повод вернуть 422 с запросом уточнения.
- `ApiError` из OpenAPI реализован Java backend. Сейчас UI показывает HTTP-статус, а не использует поля тела ошибки.

## Подключение

Настройки находятся в **`env/.env`**, создаваемом из `env/.env.example` командой `make init-config`:

```dotenv
VITE_DATA_MODE=api
VITE_API_BASE_URL=/api/v1
API_UPSTREAM=http://127.0.0.1:8000
DOCKER_API_UPSTREAM=http://host.docker.internal:8000
```

`API_UPSTREAM` — backend для локального Vite; `DOCKER_API_UPSTREAM` — backend с точки зрения контейнера nginx. Браузер обращается к тому же origin через `/api/v1`. После изменения настроек перезапустите Vite или пересоберите Docker-сервис.

С текущим backend в режиме `api` работают витрина и калькулятор товара. Общий мастер сметы и подбор комнаты потребуют ещё не реализованных `/estimate` и `/recommendations`; полный frontend-сценарий пока доступен через демонстрационный адаптер.

Таймаут — 15 секунд, `credentials: same-origin`. Ошибка сети, JSON, HTTP или схемы **не включает деморежим**. Авторизация, CSRF и production CORS требуют отдельного согласования; секретов в `VITE_*` быть не должно.
