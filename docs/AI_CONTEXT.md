# Контекст RepairCalc

Текущий стек: Vue/TypeScript → Java 21/Spring Boot → MongoDB 8. Python отвечает только за LLM и обращается к Ollama. Java — единственный владелец БД и денежных расчётов.

## Карта

- `frontend/src/`: три калькулятора, галерея, планы, административные формы; Zod проверяет ответы API.
- `backend/src/main/java/ru/repaircalc/`: `storage` — BSON и транзакции; `catalog/rules/ingestion` — immutable snapshots и импорт; `calculation` — формулы и смета; `admin` — версии, очередь, review, публикация; `llm/inspirations` — HTTP-граница и изображения.
- `llm/repaircalc_llm/`: единый внутренний HTTP-сервис; существующие estimator/classifier переиспользуются из соседних пакетов.
- `data/`: учебные каталог/правила, taxonomy, prompts, схемы и подготовленная подборка.
- `docker/`: три Dockerfile приложения, Compose, nginx, Mongo init, Ansible.
- `env/`: обычный `.env` и пустой `secret.env.example` отслеживаются Git; реальные секреты и `.env.local` игнорируются.
- `scripts/`: общий конфигуратор, локальный запуск, релиз, backup/restore и сквозная проверка.

## Инварианты

1. Java рассчитывает BigDecimal, упаковки и стоимость; BSON использует Decimal128 без потери точности. Числа модели не заменяют смету.
2. Активный указатель атомарно выбирает `catalogReleaseId + ruleSetId`. Старые ревизии и правила доступны исторически.
3. Публикация, статус карточки и аудит сохраняются одной Mongo-транзакцией. ETag относится к версии карточки.
4. Классификация привязана к версии и хешу входа; аренда и токен защищают завершение. Модель никогда не публикует товар сама.
5. Подбор исключает неподтверждённую необходимую совместимость. Обязательные зависимости задаются правилами, а не SKU/названиями.
6. Изображение выбирается только по ID из manifest. Произвольные URL не скачиваются, геометрия по фото не определяется.
7. Пустые чтения имеют объяснение деградации. Расчёт/запись при сбое БД возвращают 503. Сбой пояснения сохраняет Java-смету.
8. Production использует API. Demo-функции и fake Ollama — только тестовые/разработческие инструменты.

## Проверки

Frontend: `make check`. Java: `cd backend && ./mvnw verify` (Docker для Mongo Testcontainers). Python: `python -m unittest discover -s llm/estimation/tests`, затем `llm/classification/tests`, затем `llm/tests`; PYTHONPATH должен включать три Python-каталога. Конфигуратор: `node --test scripts/config.test.mjs`.

`python scripts/verify-stack.py --playwright` проверяет настоящие сервисы и отказы; подменяет только Ollama. Не читает локальные env-файлы и создаёт собственные volumes. Реальная модель проверяется отдельно, без автоматического скачивания. `--runtime-only --no-build` дополнительно поднимает официальный Ollama с пустым volume и проверяет весь профиль при отсутствии модели.

`python scripts/verify-stack.py --base-only --no-build` отдельно проверяет базовый запуск без Python, Ollama и сервисного токена, с настоящими production-фотографиями, их превью и деградацией анализа.

## Границы MVP

Цены, нормы и тарифы учебные. Bootstrap использует `data/*-expanded.json`: 112 товаров (12 исходных + 100 вариантов для пяти комнат и пяти стилей); исходные `*-v1.json` сохранены для регрессий. Для существующей публикации CD запускает `expand-catalog`: добавляет отсутствующие из 100 вариантов, сохраняет текущие товары/правила и переключает новую пару атомарно. Полный импорт больших исходных каталогов, коммерческие остатки/заказ, RAG, автономное принятие меток и ML-бенчмарк отложены. Обойный клей, подложки, плинтусы, демонтаж, доставка и дополнительные технологии не включены; смета содержит предупреждения. Manifest интерьеров содержит 32 фотографии Pexels: по семь гостиных, спален, кухонь, ванных, по две детских и балкона; источники, авторы и лицензия — `data/inspirations/CREDITS.md`. Mongo хранит метаданные и SHA-256, не JPEG. Pinterest API не используется. Галерея не зависит от плана/шага расчёта. Публичные build-time флаги `VITE_GUIDE_ENABLED`/`VITE_SPLASH_ENABLED` управляют первым запуском; cookie гайда — `repaircalc_guide_v1`.

Артефакт обученной корректирующей модели не задан. Публичный `useCorrection=true` возвращает 422; обычный расчёт и пояснение доступны без него. Offline-команды обучения сохранены отдельно от production HTTP-сервиса.

Исторические аудиты сохранены в PROJECT_CONTEXT_NO_JAVA.md и BACKEND_TECH_DEBT_CONTEXT.md. Актуальные проверки: IMPLEMENTATION_STATUS.md. При поиске соблюдайте AGENTS.md и `.ignore`; реальные env-файлы, логи и большие данные не загружайте целиком.

Актуальный список оставшегося функционала, визуальных заглушек и внешних входов после слияния `main`: [REMAINING_WORK.md](REMAINING_WORK.md).
